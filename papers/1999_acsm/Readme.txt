Welcome to the 1999 ACSM-WFPS-PLSO-LSAW Conference
Technical Papers CD.

Installation notes
Adobe Acrobat Reader (r) V3.0 or better is required
to view the Technical Papers.

Windows 95, 98 and NT
The Technical papers and Acrobat (if not already
installed) will automatically be installed.  If
this does not occur:
Run program SETUP.EXE from root directory on CD,
and follow instructions on screen. See README for
more information.

Macintosh
Locate the folder Reader:Reader.  Double Click on
the program Install Reader 3.0. See Readme-Reader
for more information.

Other Operating Systems
Adobe Acrobat Reader (r) is available for other
operating systems as well as those included on
This CD, from the URL: http://www.adobe.com.

Using Adobe Acrobat(r) Reader(tm) to Access the
ACSM-WFPS-PLSO-LSAW Conference CD The entire
document can be searched by keywords or by using
the title and author index on the left of the screen.
If the index is not shown, click onto the second icon
below the menu-item list.  For more information on how
to use Adobe Acrobat Reader (r), please refer to the
online help.
