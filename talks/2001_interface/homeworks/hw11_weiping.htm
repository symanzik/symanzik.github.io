This journal site introduces the features of Computational Statistics. It provides the following information of this journal.

Contents 1994-1999, and 2000. The contents are updated.

In the contents, it only listed the title and summary of the each published paper in these years. For the papers in 1999, some colorful pictures are shown, and the links to the authors are available. However, because it only contains the abstracts of papers, if we want to read the full text, we should subscribe this journal according to the subscription information, or order single article. I think this web site is a useful auxiliary of this journal, because it helps people to obtain some updated information of the journal if they are interested in it.
