 Outstanding features of Genstat:

1. The home web page of Genstat is very clear, compact, well organized =
and smooth-colored.
2. The pictures on the homepage are good guides to the info you want.
3. The search engine is at the outstanding place on the homepage, and =
very
     sensitive.
4. The Site Map on the homepage provides the users a clear map to look =
for the special software they want.
5. The negative is that there is no way to contact the other users.

Outstanding features of Ox:

1. The info on software (update, availability of extensions) is very =
clear.
2.  Downloading is very easy.
3. Links to other sites is handy on the homepage.
4. The negative is that there is no search engine.
