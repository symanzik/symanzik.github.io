Web-Based Statistics: Topics

We ended up with the following topics to be discussed in our Web-Based Statistics class this summer. The expected number of lectures on each topic is listed in parentheses. However, with the availability of new material, we may make adjustments in time and topics.

In particular, if you find an article or an interesting Web page that represents new aspects of statistics and the Web that might be worth to be presented in this class, please let me know about it and I will see how we can integrate this article/Web page into our class.

And here are the topics we have identified so far:

  • Statistical Summary Pages (1/2)

  • Data Sources on the Web (1/2)

  • Data Collection through the Web (1)

  • Interactive Data Distribution through the Web (1)

  • Electronic Publication (1):
    • Statistical Journals on the Web
    • "Emerging hot" Issues in Statistics

  • Statistical Software on the Web (4-5):
    • Documentation, Distribution, Updates, Extensions
    • Full Statistical Packages
    • Specialized Tools

  • Teaching Statistics using the Web (4-5):
    • Teachware
    • Electronic Textbooks
    • Fully electronic lecture

  • Other Issues (1):
    • People
    • Organizations
Overall, this is material for about 13 to 15 lectures. And recall that we only have 15 lectures during this condensed summer session.
