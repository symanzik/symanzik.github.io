III. Discussion

III.1 Advantages

  • Fast access to diversity of services

  • Easy to access (Mouse, Drag & Click)

  • Same service available at work, home, travel, public places, ...

  • Cheap

  • Internationalization

III.2 Disadvantages

  • Slow access & connections at many places -
    "fast-access" vs "slow-access" world

  • Security of transfered data?
    (Credit card number, Internal data)

  • Reliability of services -
    Is it still there tomorrow?
    Is this particular version still there tomorrow?
    What if person changes job or dies?
    What if Web server goes down permanently,
    company goes out of business,
    university department is closed?

  • Old versions usually deleted after update,
    i.e., no traceable history available -
    What if I want old info?
    What if data is formatted for old version?

  • Possible Solution: Internet Archives -
    Who maintains them?
    Updated how often?
    Which information stored?

  • Frequent changes of URLs -
    Will I find a particular document?

  • How to cite a URL? -
    Indicate URL and date of access

III.3 Dangers

  • Viruses through plugins & downloaded files possible

  • Possible exposure of individuals to the whole world:
    Resume, Publications, Travels, Talks, Salary,
    Leisure activities, Friends, Relationships, Families, ...

  • Who reads my e-mail or sends fraudulent e-mail?

  • Easy to track down profile of employees
    (e.g., check Netscape Cache):
    % work related pages, % leisure pages, % xxx pages, ...

  • Final Destination? -
    A network where everyone knows everything about anyone and
    has immediate access to all knowledge ever accumulated ?!? -

    That would we THIS and THIS ! -
    a species with a collective mind and memory linked through a network !
