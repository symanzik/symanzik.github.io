Course Web Pages



Advantages:
  • Dissemination of information
    • Homework assignments
    • References
    • Syllabus
    • Links to tools
    • Info on labs, help sessions
    • Instructor's contact address
    • Quizzes (old/practice)
    • Grades
    • Data sets
    • Advertisments
    • Lecture notes:
      • (+) Students can listen, do not have to write all the time
      • (+/-) Adventageous when a class is missed.
  • Accessible any time
Disadvantages:
  • Knowledge of Internet needed
  • Problems if no access at home
  • Dependence on reliability of the server
  • "Computer phobia"
  • Compatibility
