Welcome to the Stat 6720 Webpage. This page contains news and additional information regarding this class that becomes available during the semester. It is updated whenever new dates, times, or other information become available.

You can now access the full 2008 pdf version of the Stat 6720 lecture notes. Early versions of these lecture notes are accessible through the Mathematical Statistics II (Spring 2000) and Mathematical Statistics II (Spring 2001) Web pages. However, there have been numerous corrections to these notes over the last eight years so that it is strongly recommended to download the current (4/7/2008) update of these notes. While the Spring 2008 version is certainly an improvement over the Spring 2000 and Spring 2001 versions, there are still many known typos, corrections, and other improvements marked in my personal printout of these notes. The Spring 2008 version of the 6720 notes lacks a major update as it was done for the 6710/7710 notes for Fall 2008. Please be careful when using these notes. In particular do not use these notes without carefully checking the correctness of any theorems, proofs, and examples.
